# Photos

Upload original photos here (full size is fine). This folder is not published.
Web-sized copies used on the site go in `assets/img/`.

Before adding a photo, make sure:
- you have permission to use it from the person who took it and from anyone recognizable in it
- it doesn't show the faces of families who receive help
- it hasn't been edited with AI tools (enhance, background replacement, generative fill)
